# Historical archive

This archive preserves copies of every generator, test, and runbook that existed in the repository at the time of organization. Nothing was deleted. Names retain their original version labels; where a file has no date in its name, its original repository location is the authoritative historical context.

- `generators/` — all Telescopic and 5T `.il` generators.
- `tests/` — preserved regression `.il` tests.
- `runbooks/` — preserved versioned execution notes.

The canonical copies are in `canonical/`. Superseded Telescopic TotalW V1/V2 artifacts are retained here after V7 became canonical; history must not override the authority map.
