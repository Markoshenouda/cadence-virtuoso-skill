# Transistor Sizing

For each MOS provide TotalW, L, NF, M, derived W/finger, role, and rationale. The only accepted implementation relations are `W/finger = TotalW/NF`, `wf = TotalW`, and `totalM = NF*M`. Label unverified values as starting values. Require explicit user confirmation of the sizing summary before a generator is written.
