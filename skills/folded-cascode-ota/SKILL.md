## 5. Terminal routing — mandatory

Each S/G/D/B is independent:
```text
terminal -> short straight stub -> net label
```

Never physically connect terminals solely because they share a logical net, including G-D/G-B/D-B/D-S/S-B.

No diagonal, looping, through-body, overlapping, touching, or standalone decorative wires.

For actual terminal direction use transformed pin coordinates. Do not infer direction from left/right placement and do not use `inst~>bBox` center as the directional reference.

Derive axes from terminal pairs:
```text
G = G - B
B = B - G
S = S - D
D = D - S
```

The tested convention is:
```text
G RIGHT <-> B LEFT
S UP     <-> D DOWN
```

## 6. PMOS source-top rule

Every PMOS that must be source-top/drain-bottom is verified from actual transformed S/D coordinates.

Require:
```text
S.Y > D.Y
```

In the verified tsmcN65 test:
```text
MX -> FAIL
MY -> PASS
```

Do not hard-code `MY` for another PDK; verify the geometry again.

## 7. External pins and VDC-driven nets

Use `basic/iopin/symbol` + `schCreatePin` only for intentional user-facing ports.

If a net is generated by an `analogLib/vdc` source, do not also create a redundant external pin by default.

Example self-contained folded-cascode testbench:
```text
VDD       -> VDC + label       -> NO PIN
VBP_FOLD  -> VDC + label       -> NO PIN
VBN_CAS   -> VDC + label       -> NO PIN
VBN_SINK  -> VDC + label       -> NO PIN
VBN_TAIL  -> VDC + label       -> NO PIN
VINP/VINN -> VDC + label       -> NO PIN
VOUT      -> real external pin
```

Only an explicitly requested mixed VDC+pin interface is an exception.

## 8. Verified analogLib/vdc workflow

```text
Library = analogLib
Cell = vdc
PLUS center = (0.0, 0.0)
MINUS center = (0.0, -0.375)
```

Place the instance, then:
```skill
cdf = cdfGetInstCDF(inst)
cdf->vdc->value = "1.5"
```

Bias source structure:
```text
BIAS_NET -> PLUS -> VDC -> MINUS -> VSS
```

Do not physically wire VDC terminals to MOS terminals; use local labeled stubs.

### Explicit VSS reference source

When a self-contained testbench requests an explicit VSS source, create:
```text
PLUS  -> VSS
VDC   = 0 V
MINUS -> VSS
```
Both VDC terminals carry the `VSS` label. This is a zero-volt reference source and not a separate ground node.

## 10. Device sizing

Use instance CDF fields `w/l/nf/m`. Keep all W/L values explicitly labeled as starting values unless verified by device characterization and simulation.

## 11. Validation gate

Before delivery confirm:
- topology/device count
- masters and W/L/NF/M
- every S/G/D/B has a labeled net
- actual PMOS S/D geometry passes source-top requirement
- G/B and S/D are opposite directions
- no unintended terminal-to-terminal physical connection
- no looping/diagonal/overlapping stubs
- no standalone internal wires
- only intentional external pins exist
- VDC sources use instance CDF `vdc`
- VDC-driven nets have no redundant pins
- explicit VSS source, if used, is 0 V with VSS on both terminals
- Check and Save has no errors

Do not claim target gain/GBW until actual Cadence simulations verify them.
